# Archive

This directory keeps legacy code and exploratory material out of the public DCRNetV2/LRP path.

The supported public entry points are:

- `models/dcrnetv2.py`
- `models/lrp.py`
- `train.py`
- `read_dataset.py`
- `dataset/cost2100.py`
- `weights/`

Files under `archive/` are not maintained as release APIs.
